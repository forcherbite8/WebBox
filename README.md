# WebBox
A customizable Android Web Launcher to manage, organize, and access your favorite websites in one place, with offline support and privacy-focused features.
WebBox – Your Websites. One Place.

WebBox is a customizable Android Web Launcher designed to bring all your favorite websites and web apps together in one convenient place.

Instead of opening your browser and searching for the same websites repeatedly, WebBox allows you to save, organize, customize, and access your favorite websites directly from a beautiful, modern dashboard.

WebBox combines website management, browser integration, offline web access, personalization, and privacy-focused browsing features in one application.

Key Features

1. Website Management

- Add websites using their URLs.
- Automatically retrieve website icons (favicons) where supported.
- Upload custom PNG icons from device storage.
- Edit website names and URLs.
- Delete websites whenever you want.
- Automatically organize websites alphabetically (A–Z).
- Save website information locally.

2. Smart Website Dashboard

- Responsive website grid.
- Four-column layout on suitable screen sizes.
- Beautiful website cards with custom icons.
- Quick website search.
- Recently Viewed websites.
- Most Viewed websites.
- Popular Now section.
- All Websites section.

3. Custom Organization

- Pin your favorite websites.
- Create custom folders.
- Organize websites into different categories.
- Access pinned websites quickly.
- Manage saved websites from a simple three-dot menu.

4. Multiple Website Opening Modes

Choose how each website opens:

- Open in WebBox: Open websites inside the WebBox application using Android WebView.
- Open in Default Browser: Open websites using your device's default browser.
- Choose Browser: Select an installed browser or compatible application through Android's app chooser.

5. Offline & Online Support

WebBox supports both online and offline website access.

- Access websites that support offline functionality.
- Keep locally saved website information available.
- Access previously cached content when supported by the website.
- Display an internet connection message when an online-only website cannot be accessed.

Offline Mode: Websites that support offline functionality can remain accessible without an internet connection. Offline access is not guaranteed for every website.

6. Built-in Offline Games

WebBox includes an option for lightweight offline entertainment.

- Simple 2D offline games.
- Endless-runner gameplay inspired by classic browser mini-games.
- A human character instead of the traditional dinosaur.
- Play Offline option when an internet connection is unavailable.

7. Ad Blocker & Privacy Features

WebBox aims to provide a cleaner browsing experience through built-in blocking options.

Planned and supported integration features include:

- Advertisement blocking.
- Pop-up blocking.
- Tracker blocking.
- Third-party cookie controls.
- Custom filter lists.
- Website whitelist.
- Ad Blocker ON/OFF controls.
- Blocked request counter.

Note: Effective network-level advertisement and tracker blocking requires an Android-native filtering implementation. Complete ad blocking on every website cannot be guaranteed.

8. Customization & Settings

Personalize your WebBox experience.

- Custom themes.
- Upload personal background images.
- Custom font options.
- Multiple language support.
- Responsive user interface.
- Dark-themed interface.
- Custom website icons.

- Locally save added websites.
- Preserve website names and URLs.

Project Goals

The main goal of WebBox is to create a lightweight, customizable, and user-friendly Android Web Launcher.

WebBox is designed for people who frequently visit multiple websites and want a convenient way to organize and access them without repeatedly searching through their browser history or bookmarks.

The project aims to combine the simplicity of a website launcher with useful browser-like features.
